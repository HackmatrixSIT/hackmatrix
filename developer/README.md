# Developer Guide

Welcome to the developer documentation for Hackmatrix.

## Getting Started
Please refer to the setup instructions to run the application locally. Make sure to review the PRD and existing architecture guidelines before contributing.

## Technology Stack
- **Frontend/App**: Expo / React Native
- **Other Components**: Reference the `nervsync` directory for the main application codebase.

## Contribution Guidelines
1. Create a new branch for your feature or bugfix.
2. Ensure your code passes all linting and test checks.
3. Submit a Pull Request for review.
